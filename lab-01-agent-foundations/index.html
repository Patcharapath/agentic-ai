Lab 1

Agent สี่แบบใน environment เดียวกันFour agents in one environment

สร้าง reflex agent, model-based agent และ LLM agent สำหรับกล่องเอกสารขาเข้า แล้ววัดผลด้วย performance measure เดียวกันBuild a reflex agent, a model-based agent and an LLM agent for a document inbox, and score them on one performance measure

70 นาทีใน class70 min in classต่อจาก Module 1Follows Module 1Core 6 ส่วน + Stretch 1 ส่วน6 Core parts + 1 Stretch part

Lab นี้เปลี่ยนแนวคิดจาก lecture ให้เป็น code คุณจะได้เห็นด้วยตัวเลขว่า agent แต่ละแบบทำอะไรได้และไม่ได้ และทำไม agent สมัยใหม่จึงเป็น LLM ที่มี code ดูแล state อยู่รอบๆ

เมื่อจบ lab คุณจะสามารถ

  • เขียน environment, percept, action และ performance measure ของงานเอกสารเป็น code ได้
  • อธิบายด้วยผลการทดลองว่า simple reflex, model-based และ LLM agent ต่างกันอย่างไร
  • ใช้ structured output จำแนกเอกสารและดึงข้อมูล แล้ววัดความถูกต้องทีละ field
  • ชี้ได้ว่างานส่วนไหนควรให้ LLM ทำ และส่วนไหนควรให้ code ทำ

This lab turns the ideas from the lecture into code. You will see in numbers what each kind of agent can and cannot do, and why a modern agent is an LLM with code around it looking after the state.

By the end you will be able to

  • Write the environment, percepts, actions and performance measure of a document task as code
  • Explain, from experimental results, how simple reflex, model-based and LLM agents differ
  • Use structured output to classify documents and extract data, and measure accuracy field by field
  • Say which parts of a task belong to the LLM and which belong to code

6. Stopping the program, and common errors

Press Ctrl+C to stop. Documents already finished are kept. Run the same command again and the program carries on from where it stopped.

Message Cause and fix
can't open file ... No such file or directory The terminal is not in the agentic-ai folder. Go back to part 1
ModuleNotFoundError: No module named 'agentlab' You called python directly, without uv run or .venv
0 to do now when you wanted a fresh run The state from the earlier run is still there. Add --reset
error: could not start the LLM: ... Run check_setup.py to see which provider has a problem
Many lines say needs_human could not read the document The LLM could not answer. Check Ollama is running, then run with --reset

7. What the program has that the notebook did not

inbox_app.en.md in the same folder explains part by part what the code added to the notebook is for, with a sample state.json, a glossary and things to try changing. Read it alongside inbox_app.py. In short:

In the notebook In inbox_app.py Why
self.seen = set() in memory A State saved to state.json State must survive the program closing; a duplicate invoice may arrive next week
Results in a DataFrame State saved after every document; CSV written when the run ends or is stopped The person checking needs to open it, and an interrupted run must lose nothing
An LLM error breaks the cell The error is caught and that document goes to a person One document must not stop the whole batch
Edit values in the code --agent, --limit, --out, --reset Re-run with different settings without touching the file
The LLM may answer with an explanation Only 2 short fields are requested Output tokens are the slow part; asking for a written reason took a full run from 82 to 135 seconds
