Lab 3

การวางแผนและการให้เหตุผล: ตรวจสัญญากับ policyPlanning and reasoning: reviewing contracts against policy

เทียบ classical planner กับ LLM planner แล้วเทียบ ReAct, Plan-and-Execute และ Reflection บนงานตรวจสัญญาจริงCompare a classical planner with an LLM planner, then ReAct, Plan-and-Execute and Reflection on real contract review

70 นาทีใน class70 min in classต่อจาก Module 3Follows Module 3Core 7 ส่วน + Stretch 2 ส่วน7 Core parts + 2 Stretch parts

Lab นี้ตอบคำถามสองข้อด้วยการทดลอง: LLM วางแผนเก่งแค่ไหนเมื่อเทียบกับ search และในงานจริงที่ต้องตรวจให้ครบ รูปแบบการวางแผนแบบไหนแม่นที่สุด และแลกกับต้นทุนเท่าไร

เมื่อจบ lab คุณจะสามารถ

  • เขียน breadth-first search สำหรับปัญหาการวางแผนที่มี action แบบมีเงื่อนไขและผล
  • ใช้ตัวตรวจแผนกับแผนที่ LLM เสนอ และอธิบายข้อจำกัดของ LLM ในการวางแผน
  • ใช้ chain-of-thought ใน structured output และวัดผลของมัน
  • ประกอบ agent แบบ Plan-and-Execute เป็น graph ด้วย LangGraph
  • เปรียบเทียบรูปแบบการวางแผนด้วย precision, recall, F1, จำนวน LLM call และเวลา

This lab answers two questions by experiment: how good is an LLM at planning compared with search, and on real work that must be complete, which planning pattern is most accurate and at what cost?

By the end you will be able to

  • Write breadth-first search for a planning problem with conditional actions and effects
  • Check the plans an LLM proposes, and explain the LLM's limits as a planner
  • Use chain-of-thought inside structured output and measure its effect
  • Assemble a Plan-and-Execute agent as a graph with LangGraph
  • Compare planning patterns by precision, recall, F1, LLM calls and time

4. The program's options

Option What it does Default
FOLDER The folder of contract .txt files data/contracts
--pattern plan Plan-and-Execute This one
--pattern single / reflect Single call / draft then review
--pattern all Run all three and compare (about 10–15 minutes)
--contracts c1 c5 Review only some contracts All
--out PATH Folder for the results out/contract_review
--show-graph Print the Plan-and-Execute graph and stop
--help Show every option

5. Try these in order

  1. Run --show-graph and paste the text into https://mermaid.live to see the graph as a picture
  2. Run --pattern single --contracts c1 c5 (about 15 seconds) and compare with Plan-and-Execute
  3. Open out/contract_review/checks.csv in Excel and read the reasoning for the checks that failed
  4. Write a contract of your own as a .txt file in a new folder, and run the program on that folder

6. Stopping the program, and common errors

Press Ctrl+C to stop. Results for contracts already reviewed are still written to the files.

Message Cause and fix
error: no such contract(s): ... An ID given to --contracts is wrong. The message lists the IDs that exist
unchecked: R... on some lines The model failed to answer even after a retry. A person must check that rule; it is not counted as passing
error: could not start the LLM: ... Run check_setup.py to see which provider has a problem
Very slow Use --contracts to review a few at a time, and close other programs

7. What the program has that the notebook did not

contract_review.en.md explains part by part what the code added to the notebook is for. In short:

In the notebook In contract_review.py Why
Results in a dict checks.csv records the reasoning for every check The person reviewing must see why a contract was flagged
A failed check breaks the cell Rules that could not be checked are reported as unchecked Nothing silently counts as passing
Each pattern in its own cell --pattern chooses the pattern Choose between cost and accuracy with one command
3 contracts A whole folder, or a selection with --contracts Usable on real contracts

Common problems

Symptom Fix

OutputParserException The model produced incomplete JSON twice in a row. Run that cell again
