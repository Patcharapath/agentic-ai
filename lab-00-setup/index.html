เมื่อจบ lab นี้ เครื่องของคุณจะเรียก LLM ผ่าน LangChain ได้สองทาง: model ที่รันในเครื่องด้วย Ollama ซึ่งเป็น ทางหลักของวิชานี้ และ model ผ่าน API ที่ใช้ได้ฟรีเป็นทางสำรอง ทุก lab ใช้การตั้งค่าชุดนี้ จึงทำครั้งเดียว

เลือกระบบปฏิบัติการและ editor ของคุณที่แถบด้านบน คำสั่งในหน้านี้จะเปลี่ยนตาม ติ๊กช่องด้านซ้ายเมื่อทำแต่ละขั้นเสร็จ

RAM ของเครื่อง Local model ที่แนะนำ หมายเหตุ
16 GB ขึ้นไป qwen3.5:4b (ค่าเริ่มต้นของวิชา) ดาวน์โหลด qwen3.5:9b เพิ่มได้ถ้าต้องการคุณภาพสูงขึ้น

Lab ทั้งหมดออกแบบให้ทำได้ด้วย local model เพราะใช้ได้ไม่จำกัดจำนวนครั้ง ไม่ต้องใช้อินเทอร์เน็ต และข้อมูลไม่ออกจากเครื่อง ส่วน free API จำกัดจำนวน request ต่อวัน ให้ตั้งค่าไว้เป็นทางสำรอง ถ้าเครื่องของคุณรัน local model ไม่ไหว ให้แจ้งผู้สอนก่อน class แรก

By the end of this lab your machine can call an LLM through LangChain in two ways: a model running locally with Ollama, which is the main route in this course, and a model behind a free API as a backup. Every lab uses this setup, so you do it once.

Pick your operating system and editor in the bar at the top; the commands on this page change to match. Tick the boxes on the left as you finish each step.

Your RAM Recommended local model Notes
16 GB or more qwen3.5:4b (the course default) You can also download qwen3.5:9b for better quality
8 GB qwen3.5:4b Close other apps while it runs. If it is very slow, switch to the API
Less than 8 GB Skip the Ollama step Use the API only

Every lab is designed to work with the local model: it has no request limit, needs no internet, and keeps your data on your machine. Free APIs cap the number of requests per day, so set one up as a backup. If your machine cannot run the local model, tell your instructor before class 1.

ติดตั้ง uvInstall uv

5 นาที5 min

uv เป็นเครื่องมือจัดการ Python และ package มันจะดาวน์โหลด Python เวอร์ชันที่ lab ใช้ให้เอง คุณจึงไม่ต้องติดตั้ง Python แยก และไม่กระทบ Python ที่มีอยู่ในเครื่อง

เปิดแอป Terminal แล้วรัน:

curl -LsSf https://astral.sh/uv/install.sh | sh

เปิด PowerShell (กด Win แล้วพิมพ์ powershell) แล้วรัน:

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

ปิดหน้าต่าง terminal แล้วเปิดใหม่ จากนั้นตรวจว่าติดตั้งสำเร็จ:

uv --version

ควรเห็นหมายเลขเวอร์ชัน เช่น uv 0.12.x

uv manages Python and packages. It downloads the Python version the labs use by itself, so you do not need to install Python separately, and it leaves any Python already on your machine alone.

Open the Terminal app and run:

curl -LsSf https://astral.sh/uv/install.sh | sh

Open PowerShell (press Win and type powershell) and run:

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Close the terminal window and open a new one, then check the install:

uv --version

You should see a version number such as uv 0.12.x.

If it is missing, macOS shows a dialog offering to install the Command Line Developer Tools. Press Install, wait for it to finish, and run the command again.

ติดตั้ง Ollama และดาวน์โหลด local modelInstall Ollama and download a local model

15–30 นาที15–30 min

Ollama รัน LLM บนเครื่องของคุณ ข้อมูลไม่ออกจากเครื่อง และใช้ได้ไม่จำกัดจำนวนครั้ง ถ้าเครื่องมี RAM น้อยกว่า 8 GB ให้ข้ามขั้นนี้

  1. ดาวน์โหลดและติดตั้งจาก https://ollama.com/download

ต้องใช้ macOS 14 (Sonoma) ขึ้นไป หลังติดตั้งให้เปิดแอป Ollama จะมีไอคอนขึ้นที่ menu bar

ต้องใช้ Windows 10 เวอร์ชัน 22H2 ขึ้นไป หลังติดตั้ง Ollama จะทำงานอยู่เบื้องหลัง มีไอคอนที่ system tray

  1. ดาวน์โหลด model ของวิชา (ขนาดราว 3.5 GB) ใน terminal:
ollama pull qwen3.5:4b
  1. ทดสอบ:
ollama run qwen3.5:4b "สวัสดี แนะนำตัวใน 1 ประโยค"

ครั้งแรกจะช้าเพราะต้องโหลด model เข้า memory ถ้าได้คำตอบกลับมาแปลว่าใช้ได้

คุณจะเห็นข้อความช่วง Thinking... ก่อนคำตอบ เพราะ model ตัวนี้คิดเป็นขั้นตอนก่อนตอบ ซึ่งทำให้ช้าลงมาก Lab ของเราจึงปิดโหมดนี้ไว้เป็นค่าเริ่มต้น (OLLAMA_THINK=false ใน .env) และจะเปิดใช้อย่างตั้งใจใน Module 3

ทำไมเลือก model ตัวนี้

เราต้องการ model ที่ รองรับ tool calling ซึ่งจำเป็นตั้งแต่ Lab 2 ไม่ใช่ทุก model ที่ทำได้ (เช่น gemma3 ไม่รองรับ) และต้องเล็กพอสำหรับ laptop ทั่วไป การใช้ model ตัวเดียวกันทั้งห้องทำให้เทียบผลกันได้

ทางเลือกเพิ่มเติม (ไม่บังคับ)

คำสั่ง ขนาด ใช้เมื่อ
ollama pull qwen3.5:9b ราว 7 GB เครื่องมี RAM 16 GB ขึ้นไป และต้องการคำตอบที่ดีขึ้น
ollama pull scb10x/typhoon2.5-qwen3-4b ราว 2.5 GB ต้องการ model ที่ปรับมาสำหรับภาษาไทย
ollama pull bge-m3 1.2 GB Embedding model สำหรับ Lab 4 ดาวน์โหลดไว้ก่อนได้

Ollama runs an LLM on your own machine. Your data never leaves it and there is no request limit. If your machine has less than 8 GB of RAM, skip this step.

  1. Download and install from https://ollama.com/download

Requires macOS 14 (Sonoma) or later. After installing, open the Ollama app; an icon appears in the menu bar.

Requires Windows 10 version 22H2 or later. After installing, Ollama runs in the background with an icon in the system tray.

  1. Download the course model (about 3.5 GB) from a terminal:
ollama pull qwen3.5:4b
  1. Test it:
ollama run qwen3.5:4b "Hello, introduce yourself in one sentence"

The first run is slow because the model has to load into memory. If you get an answer, it works.

You will see a Thinking... section before the answer, because this model reasons step by step first, which makes it much slower. Our labs turn that off by default (OLLAMA_THINK=false in .env) and switch it on deliberately in Module 3.

Why this model

We need a model that supports tool calling, which is required from Lab 2 onwards. Not every model does (gemma3, for example, does not), and it has to be small enough for an ordinary laptop. Using the same model across the class lets us compare results.

Optional extras

Command Size Use it when
ollama pull qwen3.5:9b about 7 GB You have 16 GB of RAM or more and want better answers
ollama pull scb10x/typhoon2.5-qwen3-4b about 2.5 GB You want a model tuned for Thai
ollama pull bge-m3 1.2 GB The embedding model for Lab 4; you can download it now

ขอ API key และสร้างไฟล์ .envGet an API key and create the .env file

10 นาที10 min

API เป็นทางสำรองเมื่อ local model ช้าเกินไป และให้คุณลอง model ที่ใหญ่กว่าที่ laptop รันไหว เราแนะนำ OpenRouter เป็นตัวแรก เพราะ key เดียวเข้าถึง model ฟรีได้หลายตัว

1. สร้างไฟล์ .env

ใน terminal ของ editor (อยู่ในโฟลเดอร์ agentic-ai):

cp .env.example .env

Copy-Item .env.example .env

2. ขอ key จาก OpenRouter

  1. สมัครที่ https://openrouter.ai ไม่ต้องใช้บัตรเครดิต
  2. ไปที่ https://openrouter.ai/keys แล้วกด Create Key
  3. เปิดไฟล์ .env ใน editor แล้ววาง key หลัง OPENROUTER_API_KEY= จากนั้นบันทึกไฟล์

ข้อจำกัดของ model ฟรี (ที่ลงท้ายด้วย :free): 20 request ต่อนาที และ 50 request ต่อวัน ถ้าเคยเติมเงินรวม 10 USD ขึ้นไป จะเพิ่มเป็น 1,000 request ต่อวัน

3. เพิ่ม provider อีกตัว (ไม่บังคับ)

Agent หนึ่งงานใช้หลาย request โควตา 50 ครั้งต่อวันจึงหมดเร็ว ถ้าคุณต้องพึ่ง API บ่อย ให้มีอีกหนึ่ง provider ไว้สลับ:

Provider ขอ key ที่ ตัวแปรใน .env ข้อจำกัดของ free tier
Groq https://console.groq.com/keys GROQ_API_KEY 30 request ต่อนาที, 1,000 ต่อวัน, 8,000 token ต่อนาที
Google AI Studio https://aistudio.google.com/apikey GOOGLE_API_KEY ดูตัวเลขปัจจุบันในหน้า rate limit ของ AI Studio

4. เลือก provider เริ่มต้น

บรรทัด LLM_PROVIDER= ใน .env กำหนดว่า lab จะใช้ตัวไหน ค่าที่ใช้ได้คือ ollama, openrouter, groq, google เริ่มต้นเป็น ollama

  • API key เปรียบเหมือนรหัสผ่าน อย่าส่งให้ใคร อย่าวางในแชต และอย่าใส่ในไฟล์ code ให้เก็บไว้ใน .env เท่านั้น
  • ข้อมูลที่ส่งไป free API อาจถูกนำไปใช้ปรับปรุง model ห้ามส่งเอกสารจริงขององค์กรหรือข้อมูลส่วนบุคคล ถ้าต้องทดลองกับเอกสารจริงให้ใช้ Ollama

An API is the backup for when the local model is too slow, and it lets you try models bigger than a laptop can run. We suggest OpenRouter first, because one key reaches several free models.

1. Create the .env file

In the editor's terminal (inside the agentic-ai folder):

cp .env.example .env

Copy-Item .env.example .env

2. Get an OpenRouter key

  1. Sign up at https://openrouter.ai. No credit card is needed.
  2. Go to https://openrouter.ai/keys and press Create Key.
  3. Open .env in the editor, paste the key after OPENROUTER_API_KEY=, and save the file.

Limits for free models (those ending in :free): 20 requests per minute and 50 requests per day. If you have ever bought 10 USD of credit or more, that rises to 1,000 requests per day.

3. Add another provider (optional)

One agent task uses many requests, so 50 a day runs out quickly. If you rely on the API often, have one more provider to switch to:

Provider Get a key at Variable in .env Free-tier limits
Groq https://console.groq.com/keys GROQ_API_KEY 30 requests per minute, 1,000 per day, 8,000 tokens per minute
Google AI Studio https://aistudio.google.com/apikey GOOGLE_API_KEY See the current numbers on AI Studio's rate limit page

4. Choose the default provider

The LLM_PROVIDER= line in .env decides which one the labs use. Valid values are ollama, openrouter, groq, google. It starts as ollama.

  • An API key is like a password. Do not send it to anyone, paste it in a chat, or put it in a code file. Keep it in .env only.
  • Data sent to a free API may be used to improve the model. Never send real company documents or personal data. If you need to experiment with real documents, use Ollama.
